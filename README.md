📊SALES PERFORMANCE DASHBOARD ANALYSIS

Interactive Sales Performance Dashboard built in Microsoft Excel using data cleaning, Pivot Tables, KPI cards, Pivot Charts, and Slicers to analyze revenue, profit, customer contribution, regional performance, and product performance.

Project Overview

This project presents an interactive Sales Performance Dashboard developed in Microsoft Excel to analyze business performance across products, customers, regions, sales representatives, and time periods.

The project demonstrates the complete analytics workflow from data preparation and cleaning to dashboard development and insight generation.

Using Pivot Tables, Pivot Charts, KPI Cards, and Slicers, the dashboard enables users to explore sales performance dynamically and identify key drivers of revenue and profitability.

🎯 Business Objectives

The analysis was designed to answer the following business questions:

* How much revenue and profit has the business generated?
* Which customers contribute most to revenue?
* Which sales representatives perform best?
* Which regions generate the highest sales and profits?
* Which product categories contribute most to business performance?
* What impact do discounts have on profitability?

Dashboard Features:
